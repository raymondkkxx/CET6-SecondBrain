# 实体卡：六级高频学术动词与态度词 (Academic Reporting Verbs & Attitudes)

> 阅读理解与听力讲座中，作者或受访学者经常通过特定的**引述动词（Reporting Verbs）**直接暴露其立场褒贬。抓住这一个词即可秒杀态度题与观点题。

---

## 1. 表示“质疑、反驳、批评”的引述动词（负向立场）
- **`contend / argue to the contrary`**：反驳道，主张相反观点
- **`challenge / question / cast doubt on`**：对……提出质疑
- **`refute / debunk / discredit`**：驳斥，揭穿（错误理论/传言）
- **`lament / bemoan / deplore`**：痛惜，哀叹，强烈不满（常用于作者对某种社会退步现象表态）
- **`caution / warn against`**：告诫，警告不要……
- **`criticize / denounce / condemn`**：批评，谴责

---

## 2. 表示“拥护、赞同、强调”的引述动词（正向立场）
- **`advocate / champion / endorse`**：倡议，拥护，背书支持
- **`applaud / hail / acclaim`**：称赞，欢呼，高度评价（`hail X as a breakthrough`）
- **`underscore / highlight / accentuate`**：强调，突显
- **`validate / corroborate / substantiate`**：证实，佐证（某假设或结论正确）
- **`subscribe to / concur with`**：赞同，同意（某观点）

---

## 3. 表示“揭示、归因、预测”的客观学术动词（中性立场）
- **`attribute A to B` / `ascribe A to B`**：把 A（结果）归因于 B（原因）
- **`demonstrate / reveal / unveil`**：揭示，表明
- **`speculate / hypothesize`**：推测，假设（尚未最终证实）
- **`project / forecast / anticipate`**：预测，预计
