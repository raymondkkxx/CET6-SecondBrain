# 听力场景高频词群汇总 (Listening Scenario Lexicon)

> 配合 `01-projects/听力/六级听力语料核心主题分类.md` 使用。以下词群为录音高频播音词与选项对应词，刷题前速读可大幅提升辩音反应速度。

---

## 1. 职场与商业经济场景（Section A & C 极高频）
- **招聘与晋升**：`recruit / hiring`（招聘）、`candidate / applicant`（候选人）、`resume / curriculum vitae (CV)`（简历）、`probation period`（试用期）、`promotion`（晋升）、`glass ceiling`（职场晋升天花板）、`turnover rate`（员工流失率）、`layoff / downsizing`（裁员）。
- **办公与薪酬**：`remote / hybrid work`（远程/混合办公）、`flexible hours`（弹性工时）、`burnout`（职业倦怠）、`fringe benefits / perks`（额外福利）、`incentive / bonus`（奖金激励）、`workload`（工作量）、`delegate tasks`（委派任务）。
- **企业与市场**：`start-up`（初创公司）、`venture capital`（风险投资）、`revenue / profit margin`（营收/利润率）、`market share`（市场份额）、`launch a campaign`（发起营销活动）、`consumer loyalty`（消费者忠诚度）、`recession / downturn`（经济衰退）。

---

## 2. 心理学与认知实验场景（Section C 讲座头号题源）
- **实验要素**：`hypothesis`（假设）、`subject / participant`（实验被试）、`control group`（对照组）、`variable`（变量）、`correlation`（相关性）、`longitudinal study`（纵向长期研究）、`empirical evidence`（实证证据）、`questionnaire / survey`（问卷调查）。
- **认知与情绪**：`cognitive bias`（认知偏差）、`short-term / working memory`（短期/工作记忆）、`attention span`（注意力持续时间）、`procrastination`（拖延症）、`empathy`（共情/同理心）、`resilience`（心理韧性）、`chronic stress`（慢性压力）、`self-esteem`（自尊）、`intrinsic motivation`（内在动机）。

---

## 3. 医疗健康与生理科学场景（Section A & B 高频）
- **疾病与症状**：`chronic disease`（慢性病）、`cardiovascular`（心血管的）、`obesity`（肥胖）、`diabetes`（糖尿病）、`immune system`（免疫系统）、`infectious / contagious`（传染性的）、`insomnia / sleep deprivation`（失眠/睡眠剥夺）、`fatigue`（疲劳）。
- **营养与疗法**：`metabolism`（新陈代谢）、`calorie intake`（卡路里摄入）、`sedentary lifestyle`（久坐不动的生活方式）、`moderate exercise`（适度运动）、`nutrient / dietary supplement`（营养素/膳食补充剂）、`circadian rhythm`（昼夜节律/生物钟）。

---

## 4. 生态环境与前沿科技场景（Section B & C 常客）
- **环境气候**：`greenhouse gas emissions`（温室气体排放）、`carbon footprint`（碳足迹）、`renewable energy`（可再生能源）、`deforestation`（森林砍伐）、`habitat loss`（栖息地丧失）、`endangered species`（濒危物种）、`biodegradable`（可生物降解的）、`microplastics`（微塑料）。
- **数字科技**：`automation`（自动化）、`algorithm`（算法）、`cybersecurity`（网络安全）、`data breach`（数据泄露）、`virtual reality (VR)`（虚拟现实）、`autonomous vehicles`（自动驾驶汽车）、`cutting-edge / state-of-the-art`（最前沿的）。
