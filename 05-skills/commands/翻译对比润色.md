# 指令：翻译对比润色 (`/check-translation`)

## 触发方式
用户发送中文原文（及自己的英文译稿），下令 `/check-translation`。

## AI 执行标准
1. **逐句主干切分方案**：
   - 将中文段落按意群切分为 5-7 个标准句。
   - 标明每句的 **`主语 (S) + 唯一核心谓语 (V)`**，以及其余动词转化为非谓语（`doing / done / to do`）或从句的具体方式。
2. **双版本译文对照**：
   - **考场稳健版（75+分）**：用最基础但绝对不出错的六级核心词与句型完成翻译（适合考场救急）。
   - **高阶满分版（90+分）**：采用地道被动语态、同位语及高级固定搭配。
3. **核心词块入库提取**：列出本篇必背的 5-8 个核心汉英词块对。
