# 指令：长难句秒切解析 (`/parse-sentence`)

## 触发方式
用户发送任何看不懂的英文长句并下令 `/parse-sentence`（或“切这个句子”）。

## AI 执行标准
1. **三秒极简主干**：用粗体直接输出该句最核心的 **`主语 + 谓语 + 宾语/表语`**（不超过 8 个单词）。
2. **结构分层拆解（括号剥离法）**：
   - 标出让步/原因状语从句：`[状语: ...]`
   - 标出插入语与后置定语：`(修饰: ...)`
   - 标出核心考点所在句。
3. **直译与顺译对照**：给出考场直译逻辑链，以及流畅中文译文。
4. **可复用亮点提取**：提取句中可用于写作或常考阅读替换的 1-2 个高价值词块。
