# 指令：错题深度解剖 (`/analyze-error`)

## 触发方式
用户直接发送阅读或听力错题的【题干 + 四个选项 + 原文对应段落】并附带指令 `/analyze-error`（或直接下令“解剖这道错题”）。

## AI 执行标准（严禁废话，严格按以下四步输出）
1. **题干精准定位锚点**：标出题干中的核心定位词（`[定位词1]` + `[定位词2]`），直接指出对应原文的第几句。
2. **正确选项同义替换映射表**：
   - `原文词块 A` $\Longleftrightarrow$ `正确选项词块 A'`
   - `原文词块 B` $\Longleftrightarrow$ `正确选项词块 B'`
3. **其余三个干扰项死因鉴定**：
   - **选项 X**：【无中生有 / 原词拼凑但主谓颠倒 / 因果倒置 / 偷换概念 / 正反混淆】—— 指出具体哪个词与原文冲突。
4. **核心词汇提取**：从该题提取 2-3 个高频核心词或同义替换对，按标准格式追加至 `02-areas/vocabulary/六级高频核心词与同义替换总表.md` 或 `06-wiki/analyses/`。
