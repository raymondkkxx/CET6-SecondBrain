# 30天冲刺500分作战蓝图 (30-Day 500+ Master Plan)

> 本蓝图按最高提分效率设计，将 30 天切分为三大战役阶段。你拥有绝对的调整权，可随时根据状态加速、跳过或重排任意模块。

---

## 阶段一：底层爆破与题型破译（Day 01 - Day 10）
**阶段目标**：掌握核心高频词与同义替换词群，彻底跑通“听力定位”与“阅读定位”两大高分引擎。

| 天数 | 核心词汇任务 | 听力攻坚 (25-30 min) | 阅读攻坚 (35-40 min) | 写译突破 (20 min) |
| :--- | :--- | :--- | :--- | :--- |
| **Day 01** | 核心同义替换词群 Group 1-2 | 摸底测试 1 套听力，定位薄弱 Section | 摸底测试 1 套阅读，统计各题型耗时 | 拆解写作“现象阐述型”三段式模板 |
| **Day 02** | 核心同义替换词群 Group 3-4 | Section A 长对话专项（2篇）+ 问答逻辑分析 | 仔细阅读专项（2篇）：只练“题干定位+首尾句” | 拆解写作“双边对比讨论型”模板 |
| **Day 03** | 核心同义替换词群 Group 5-6 | Section C 讲座专项（2篇）：抓转折/因果信号词 | 仔细阅读专项（2篇）：事实细节题同义改写对比 | 翻译核心句法：主谓宾定状补语序重构 |
| **Day 04** | 致命熟词僻义清单 Part 1 | Section B 短文理解（2篇）：首句定主题训练 | 长篇匹配专项（1篇）：双关键词极速扫读法 | 翻译高频词块：历史文化与传统技艺 |
| **Day 05** | 致命熟词僻义清单 Part 2 | Section C 讲座专项（3篇）：视听一致与替换演练 | 仔细阅读专项（2篇）：观点态度题与推理判断题 | 写作高分句型：倒装、强调、非谓语植入 |
| **Day 06** | 学术态度词与逻辑连接词 | 听力整套限时训练（Set 2） | 阅读整套限时训练（Set 2，放弃选词填空恋战） | 翻译高频词块：生态环境与可持续发展 |
| **Day 07** | **阶段复盘 1**：清理前6天盲点词 | 重听 Set 1-2 错题音频（1.25倍速） | 整理 Set 1-2 阅读全部同义替换对 | 独立默写 1 篇双边议论文框架 |
| **Day 08** | 听力职场与商业高频词群 | Section A 长对话专项（4篇连刷） | 仔细阅读专项（2篇）+ 长难句三步秒切 | 翻译高频词块：科技创新与经济社会 |
| **Day 09** | 听力心理与认知高频词群 | Section C 讲座专项（3篇连刷） | 长篇匹配专项（2篇连刷，目标每篇 ≤12分钟） | 写作论证段扩展：因果法 + 举例法语料背诵 |
| **Day 10** | 阶段一总词表快刷 | 听力整套限时训练（Set 3） | 阅读整套限时训练（Set 3） | 段落翻译真题实战 2 篇 + 对照改写 |

## 阶段二：真题高强度对抗与提速（Day 11 - Day 20）
**阶段目标**：将单模块正确率稳定在 500+ 基准线以上（听力 18/25，仔细阅读 8/10，匹配 9/10）。

| 天数 | 核心词汇任务 | 听力高强对抗 | 阅读高强对抗 | 写译高强对抗 |
| :--- | :--- | :--- | :--- | :--- |
| **Day 11** | 真题 Set 1-3 错题词复盘 | 真题 Set 4 听力全套 + 错题定位句精听 | 真题 Set 4 阅读全套（限时 38 分钟） | 真题 Set 4 作文限时 28 分钟完稿 |
| **Day 12** | 听力科技与生态高频词群 | 真题 Set 5 听力全套 + 同义替换复盘 | 真题 Set 5 阅读全套（限时 38 分钟） | 真题 Set 5 翻译限时 22 分钟完稿 |
| **Day 13** | 阅读高频抽象名词词群 | Section C 魔鬼训练（4篇讲座连刷） | 仔细阅读魔鬼训练（4篇连刷，错题归因） | 写作“问题解决型”模板与万能对策句 |
| **Day 14** | **阶段模考 2** | **真题 Set 6 全真计时模考** | **严格按考场流程走完 130 分钟** | **模考后按赋分表计算总分并定位短板** |
| **Day 15** | 模考卷 Set 6 生词榨干 | Set 6 听力逐题复盘：分析干扰项设坑方式 | Set 6 阅读逐题复盘：分析定位偏差原因 | 使用 `/polish-essay` 升格 Set 6 作文 |
| **Day 16** | 选词填空高频词性后缀表 | 真题 Set 7 听力全套 | 真题 Set 7 阅读全套 + 选词填空词性标注法 | 真题 Set 7 翻译实战（无词典硬译训练） |
| **Day 17** | 写作高级替换词（替代 good/important） | 真题 Set 8 听力全套 | 真题 Set 8 阅读全套 | 真题 Set 8 写作实战（名言/谚语类破题） |

| **Day 19** | 听力医疗健康与教育词群 | 真题 Set 9 听力全套 | 真题 Set 9 阅读全套 | 真题 Set 9 写译连测（限时 55 分钟） |
| **Day 20** | 阶段二错题词总清扫 | 重听 Set 7-9 所有错题音频片段 | 复盘 Set 7-9 仔细阅读干扰项特征 | 汇总个人专属写作黄金 15 句 |

## 阶段三：全真模考与考场定型（Day 21 - Day 30）
**阶段目标**：固化考场时间分配肌肉记忆，消除一切临场卡壳，确保稳定输出 500+。

| 天数 | 作战核心内容 | 关键执行指标 |
| :--- | :--- | :--- |
| **Day 21** | **全真模考 Set 10**（上午/下午整块时间） | 严格卡表：写作 30m → 听力 30m → 阅读 40m → 翻译 30m |
| **Day 22** | Set 10 深度解剖 + 薄弱题型靶向补刀 | 针对模考中低于目标分的模块，单点加练 2 组 |
| **Day 23** | **全真模考 Set 11** | 验证阅读“先匹配、再仔细、最后选词”的时间余量 |
| **Day 24** | Set 11 深度解剖 + 听力讲座突击 | 集中攻克 Section C 中“实验结论/学者观点”题 |
| **Day 25** | **全真模考 Set 12** | 检验写作模板默写速度（目标 22 分钟内写完 180 词） |
| **Day 26** | Set 12 深度解剖 + 翻译高频句型回炉 | 重点扫荡翻译中的非谓语动词、定语从句与同位语结构 |
| **Day 27** | 历年真题同义替换总表通读（第 1 遍） | 遮住中文/同义词，极速反应核心词汇的替换链条 |
| **Day 28** | 写作三大万能框架闭眼默写 + 翻译四大主题词速刷 | 确保写译保底 145+ 分的弹药完全上膛 |
| **Day 29** | **终极热身模考（Set 13 精选）** + 听力原速磨耳 | 保持考场手感，不再纠结偏难怪题 |
| **Day 30** | **考前终极核查清单** | 过一遍 [考场时间分配与抢分铁律](../../03-resources/references/考场时间分配与抢分铁律.md) 与个人万能模板 |
