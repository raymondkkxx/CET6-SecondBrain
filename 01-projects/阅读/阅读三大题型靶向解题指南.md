# 阅读三大题型靶向解题指南 (Reading Tactical Guide)

> 阅读总分 248.5 分（40分钟），是 500+ 战役中**最可控、回报率最高**的模块。核心铁律：**改变做题顺序，严控时间分配**。

---

## 1. 黄金做题顺序与时间分配
**严禁按试卷印刷顺序（A→B→C）做题！** 必须按分值高低执行 **C → B → A** 策略：

1. **第一步：Section C 仔细阅读（2篇，10题，占20% / 142分）**
   - **限时**：**18 - 20 分钟**（每篇 9-10 分钟）。
   - **目标**：对 **8 - 10 题**（拿到 113 - 142 分）。
2. **第二步：Section B 长篇匹配（1篇，10题，占10% / 71分）**
   - **限时**：**12 - 13 分钟**。
   - **目标**：对 **9 - 10 题**（拿到 64 - 71 分）。
3. **第三步：Section A 选词填空（1篇，10题，占5% / 35.5分）**
   - **限时**：最后剩下的 **5 - 7 分钟**。
   - **目标**：对 **5 - 7 题**即可（每题仅 3.55 分，绝不在此浪费时间）。

---

## 2. Section B 长篇匹配（10分钟拿满71分操作流）

### 第一步：划出 10 个题干的“双定位词”（3分钟）
- **绝对不选做定位词的词**：文章主题词（每段都有，毫无区分度）。
- **第一顺位（显眼定位词）**：数字、年代、大写专有名词（人名/机构名/地名）、连字符合成词、特殊符号、最高级（`most / first`）。
- **第二顺位（核心实词组合）**：`特征形容词 + 具体名词` 或 `特殊动词 + 宾语`。每道题至少划出 **2-3 个** 关键信息点。

### 第二步：按段落从 A 到 O 顺次扫读匹配（9分钟）
- **优先看每段首尾句 + 转折句**：长篇阅读 70% 的匹配点位于段落前两句、最后一句或 `however / but` 之后。
- **双词重合锁定法**：当某一段同时出现了某个题干的 **2 个及以上定位词（或其同义改写）**，立即填涂该段字母，无需通读全段！
- **重叠段标记**：六级长篇匹配通常有 1-2 个段落会被选两次。如果某段特别长（含两个明显的意群或转折），做个星号标记，留心二次匹配。

---

## 3. Section A 选词填空（5分钟极速收割流）

### 第一步：15 个备选词按词性归类（1.5分钟）
无需深究生僻词义，直接看后缀标出四大词性：
- **`n.`（名词）**：`-tion / -ment / -ness / -ity / -ance / -cy`
- **`v.`（动词）**：原形、`-ed`（过去式/过去分词）、`-ing`（现在分词）
- **`adj.`（形容词）**：`-ive / -ous / -ful / -able / -al / -ic / -ent`
- **`adv.`（副词）**：`-ly`（最好做，通常只有 2-3 个备选词，直接秒选）

### 第二步：看空格前后语法结构定词性（3.5分钟）
1. **秒杀副词（`adv.`）**：空格位于完整句子中，如 `have [___] changed`（助动词与实义动词之间）或修饰形容词 `is [___] important`，直接从 2-3 个 `-ly` 副词中二选一。
2. **秒杀形容词（`adj.`）**：`冠词(a/an/the) + [___] + 名词` -> 选形容词或分词。
3. **秒杀名词（`n.`）**：`形容词 + [___]` 或 `介词(of/in/for) + the + [___]` -> 选名词。
4. **秒杀动词原形（`v.`）**：情态动词 `can/will/may/should + [___]` 或不定式 `to + [___]` -> 选动词原形。
5. **剩余难空直接蒙**：最后剩 2-3 个纠结的空，选同词性里最眼熟的词填上，立即转战翻译！
